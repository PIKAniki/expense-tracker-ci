# Changelog

## 1.1.0 – 2026-11-05

- Документация: руководство пользователя, описание разработки и CI.
- Javadoc публикуется на GitHub Pages после каждой успешной сборки main.
- CI разделён на три workflow: build, docs, release.

## 1.0.0 – 2026-11-05

- Команда `month <yyyy-MM>` – сумма расходов за месяц.
- Сумму можно вводить с запятой: `99,90`.
- Нулевые и отрицательные суммы не сохраняются.
- Путь к файлу данных задаётся свойством `expenses.file`.
- Unit- и интеграционные тесты, сборка и проверка в GitHub Actions.

## 0.1

- Первая версия: команды `add`, `list`, `total`.
